# Code2Chill — Club Website

A website project being developed for **Code2Chill**, the student-led technical club at Chitkara University.

The project aims to create a modern, interactive platform to showcase the club's identity, introduce its team, highlight events, display student projects, and provide information for students interested in joining the community.

A student-developed website project for Code2Chill, the technical club at Chitkara University. Built using React and Vite, with plans for MERN stack integration.
---

## About Code2Chill

Code2Chill is a student-led technical club focused on innovation, technical excellence, and practical learning.

The club encourages students to explore technology, develop their skills, collaborate on projects, participate in technical events, and solve real-world problems.

Its areas of interest include:

- Software Development
- Web and Mobile App Development
- Artificial Intelligence and Machine Learning
- Cybersecurity
- Cloud Computing
- Internet of Things (IoT)
- Emerging Technologies

## Project Overview

This project is the development of an official website for Code2Chill.

The goal is to create a visually engaging, responsive, and dynamic platform that represents the club and makes its activities accessible to students.

### Planned Website Sections

- **Home:** Introduction to Code2Chill and its vision.
- **About:** Club introduction, objectives, and activities.
- **Team:** Club leadership and team members.
- **Events:** Upcoming, ongoing, and past technical events.
- **Projects:** Projects and innovations developed by club members.
- **Join Club:** An entry point for students interested in joining the club.

## Run the Project Locally

Follow these steps to run the frontend on your computer.

### 1. Clone the repository

```bash
git clone https://github.com/akshita-1810/Code2Chill-Website.git
```

### 2. Open the project folder

```bash
cd Code2Chill-Website
```

### 3. Navigate to the frontend

```bash
cd frontend
```

### 4. Install dependencies

```bash
npm install
```

### 5. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal, usually:

`http://localhost:5173/`
