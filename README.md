# Code2Chill — Club Website Project

A website project being developed for **Code2Chill**, the student-led technical club at Chitkara University.

The project aims to create a modern, interactive, and responsive platform to showcase the club's identity, introduce its team, highlight events, display student projects, and provide information for students interested in joining the community.

---

## About Code2Chill

Code2Chill is a student-led technical club focused on innovation, technical excellence, and practical learning.

The club encourages students to explore technology, develop their skills, collaborate on projects, participate in technical events, and solve real-world problems.

Its areas of interest include:

- Software Development
- Web and Mobile App Development
- Artificial Intelligence and Machine Learning
- Cybersecurity
- Cloud Computing
- Internet of Things (IoT)
- Emerging Technologies

## Project Overview

This project involves developing a website for Code2Chill to establish a strong digital presence for the club.

The platform is designed to introduce students to the club, showcase its activities, highlight the people behind it, and provide information about events and projects.

The long-term goal is to make the website dynamic, allowing club information and content to be managed and updated through a backend and database rather than requiring changes directly in the frontend code.

## Website Features

### 1. Home Page
- Introduction to Code2Chill.
- Club branding and visual identity.
- Navigation to important website sections.
- Quick overview of club activities.

### 2. About Page
- Introduction to the club.
- Club vision, objectives, and areas of interest.
- Information about the club's activities and learning environment.

### 3. Team Page
- Introduction to club leadership.
- Core team member profiles.
- Team structure and responsibilities.

### 4. Events Page
- Interactive event explorer.
- Event search functionality.
- Category-based filtering.
- Upcoming, ongoing, and past event sections.
- Event details popup.

### 5. Projects Page
- Project cards and descriptions.
- Technology tags.
- Category-based filtering.
- Search functionality.
- Individual project details popup.

### 6. Join Club Page
- Planned section for students interested in becoming part of Code2Chill.

## Run the Project Locally

Follow these steps to run the frontend on your local machine.

### 1. Clone the repository

```bash
git clone https://github.com/akshita-1810/Code2Chill-Website.git
```

### 2. Navigate to the project folder

```bash
cd Code2Chill-Website
```

### 3. Navigate to the frontend directory

```bash
cd frontend
```

### 4. Install dependencies

```bash
npm install
```

### 5. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal, usually:

`http://localhost:5173/`
